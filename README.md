# John Arman Cabalfin — Web & Systems Developer

A single-page developer portfolio built with plain HTML, CSS, and JavaScript — no framework, no build step. Showcases four complete, role-based web systems (a barangay e-government portal, an OJT/internship tracking platform, a home-service booking & dispatch platform, and a PC game distribution site), plus services, pricing, and contact info.

**🔗 Live demo:** [johnarman-portfolio](https://johnarmancabalfin.github.io/johnarman-portfolio/)

## Tech stack

- HTML5 / CSS3 / vanilla JavaScript
- Google Fonts (Space Grotesk, JetBrains Mono, Inter)
- No frameworks or build tools — deploys as a static site anywhere

## Structure

```
Portfolio/
├── index.html          # Main page (all sections)
├── assets/
│   ├── css/style.css   # All styling
│   ├── js/script.js    # Project data, modal/gallery logic, interactions
│   ├── favicon.svg
│   └── image/           # Project screenshots, grouped by system
├── .gitignore
└── README.md
```

## Running locally

No build step required — just open `index.html` in a browser, or serve the folder with any static server, e.g.:

```bash
npx serve .
```
